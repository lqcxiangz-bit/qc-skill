# 设计与连续感（生成 HTML 时遵守）

这份文件是页面的硬约束，也是让它「不像 AI 默认套模板」的依据。最重要的一条排在最前面。

---

## 0. 连续感优先——长卷不割裂（这版最核心的规则）

**症状**：把一份 skill 的原文逐段翻译批注时，容易把它切成几个**带边框 / 背景色块 / 阴影的大卡片**，每段成了一座孤岛。明明是同一份 skill，被样式一切，读起来支离破碎、像一堆互不相干的幻灯片。

**根因**：
1. 每段一个 card（有 border / box-shadow / 独立背景）→ 视觉孤岛。
2. 段间留白过大 → 断裂。
3. 章节标题做成整行大横幅 → 把流打断。

**解药（模板已内置，改内容时别破坏）**：

- **不给每段做卡片。** 整个逐段课堂共用同一张纸（同一背景色，无 border、无 shadow、无每段独立底色）。
- **段与段只用一条发丝细线（`--hair`）分隔** + 页边一个小段号。分隔要「有但不吵」。
- **一条贯穿脊线**（`.classroom::before`）从第一段拉到最后一段，不断线，把所有段缝成「同一卷」。这是 signature——读者一眼看出这是一份连续文档，不是散段。
- **段号是挂在脊线上的小节点**（圆点），关键段用实心点、连接段用空心点，形成一条可扫读的节奏线。
- **章节标题轻量化**：页边中文序数 + 一行小标题，不做整行横幅。
- **统一栏宽、统一行高**：所有段落同一个 grid、同一 line-height，读起来是一份文档的呼吸，不是一屏一个样。
- **折叠态保持紧凑**，让原文顺畅往下流；**展开批注是唯一被编排的动作**（一次 `max-height` 过渡），冲击力集中在这一下。

一句话：**分隔靠节奏（线 + 号 + 脊线），不靠盒子。**

## 1. Hero 是一篇论点，不是介绍

Hero 要表态、可被反驳。介绍式（「本文将拆解 XX」）安全但无味；论点式（「这不是一个工具，是一段被注入的设计总监人格」）断言了本质。**用断言式标题**，不要用「分析 / 拆解 / 解读」这种中性词起头。

## 2. 字体承载个性（系统栈兜底，可换）

- **展示衬线**（有性格、克制用）：标题、章节序数。可用 Fraunces；默认用系统 `Songti SC / Georgia`。
- **正文衬线**（可读、中性偏暖）：正文、译文、批注。可用 Spectral。
- **等宽**（只给标签 / 眉标 / 段号）：JetBrains Mono / 系统 mono。**批注正文不要用等宽**——排中文别扭、字距不自然，用正文衬线 + 行高 1.8 立刻顺眼。
- 字阶要有层次：标题大、正文中、标签小。不要全靠加粗分层级。
- 默认用系统衬线栈保证**离线单文件**；若允许联网，在 `<head>` 引 Google Fonts 再改 `--font-*` 变量。

## 3. 不要暗色系（用户明确偏好）

- 背景纸色 `#f6f2e9`（偏冷的暖纸，避开 AI 默认奶油 `#F4F1EA`）。
- 文字墨褐 `#2a2620`，不是纯黑。
- 点缀：朱砂 `#c0392b` / 深金 `#8a6d2f` / 苔绿 `#3a6b5b`。
- 全页无黑块、无近黑背景、无暗色终端卡。运行轨迹用纸色卡片，不要做成暗色「终端」样。

## 4. 小字要够大（页面好看但看得清）

- 已经很大的（Hero 标题、章节序数）保持不动。
- 正文 / 译文：**17px**。
- 英文原文（参照用，略小）：**16px**，斜体。
- 批注正文：**16px**。
- 眉标 / 标签 / 段号：**12–13px**（等宽合理）。
- 移动端兜底：正文 16px、批注 15.5px。

## 5. 结构即信息

结构装置（编号、眉标、分隔线、标签）要编码内容本身，不是装饰。

- 章节用 序/壹/贰/叁 中文序数——它们确实是顺序结构，可以。
- **并列的点不要编号**。几个并列要点用项目符号或标签，别套 01/02/03——那是 AI 最爱的假结构。
- 双栏中间的竖线、批注左侧的竖线，都是编码「这是两种内容 / 这是批注」的语义分隔，不是装饰。

## 6. 刻意使用动效

- 批注展开用 `max-height` 过渡（约 0.4s ease），目的明确。
- **不要**散落的 fade-in-up、stagger 入场、hover scale——它们强化「这是 AI 生成的」感觉。
- 一个被编排过的瞬间（批注展开），比一堆散落效果有冲击力得多。

## 7. 把胆量花在一个地方 + 对抗 AI 默认审美

当前 AI 生成的设计默认聚在三种长相：① 暖奶油 + 高对比衬线 + 赤陶点缀；② 近黑背景 + 单一酸性亮色；③ 大报式 + 发丝线 + 零圆角密集分栏。

这套页面**踩在默认 ① 的边上**（暖纸 + 衬线 + 朱砂）。所以独特性**不能押在配色上，要押在结构和机制上**：

- 双语双栏 + 可展开批注的机制本身是 signature。
- **贯穿脊线把所有段缝成「同一卷」，是 signature（也正是解决割裂感的那条脊线）。**
- 批注圆章、段号节点的视觉是 signature。

signature **集中在这一处**，其余安静克制——不要同时把配色渐变、复杂动效、装饰编号都铺上去。

## 8. 明确拒绝

- 在读者理解内容前就甩 A/B/C 等级（本 skill 不打字母等级）。
- 以审计式的好坏判断组织全文——判断服务学习，转成「学走 / 别照搬」。
- 承诺全文精读却自行减段（做不到就明说「选段」）。
- 为了模仿目标 skill 的外观而破坏这套教学 / 连续系统。
- 单文件之外的任何外部请求（远程字体、CDN、远程图片、统计）。
