# 批注怎么写

批注是第四问的全部价值。它要同时做到两件事：**让一个不懂的人看懂**，**并且挖到作者当初为什么这么定**。

一条批注如果删掉之后只剩「这句很重要 / 很巧妙 / 体现了深刻的思考」，那就是没写，重写。

---

## 一、先填格子，再写话

老办法是给一张「五种追问角度」的清单，让人记着照做。**清单拦不住任何人。** 所以改成填格子——格子空着就是没写完，一眼看得出来。

### 每条深批注必填：那个选择

> 「它本来可以 ______，但它选了 ______，因为 ______。」

三个空都得填满。这个句式逼你干一件事：**先找出一个看着更自然、更常见的做法，再说清它为什么偏偏不用。**

✅ 「它本来可以让模型自己判断哪些段落重要，但它选了给一把尺子（禁令带不带理由），因为『重要』是个模糊词，两个人读同一段会给出不同答案，而『带不带理由』一眼可查。」

❌ 「这里强调了判断标准的重要性。」（没有替代做法、没有取舍、等于复读）

**填不满三个空怎么办？** 说明这段可能不是关键段——那就只写一句简单带过，别硬凑。把深度留给真有取舍的地方。

### 遇到「不要这样做」，另填三格

禁令后面的括号，是**整份 skill 里密度最高的一行**——一次事故被压到了最小。批注负责把它解压回去：

| 格子 | 填什么 |
|---|---|
| **出了什么事** | 当时看到的现象 |
| **为什么会这样** | 这个系统的哪条性质导致的 |
| **不躲会怎样** | 代价 |

> 例：`不要用 SOLID（会渲染成黑色）`
> **出了什么事**：页面上那一块整个变成黑的。
> **为什么会这样**：那个词触发了主题的深色变量，背景和文字撞成同色。
> **不躲会怎样**：读者看到一块纯黑，以为页面坏了，直接关掉。

**理由不一定长成括号。** 藏在正文里的「因为…」「否则会…」，同样是压缩包，照样解压。

**但先分清哪种禁令值得花力气：**

| 这条禁令 | 怎么处理 |
|---|---|
| **带着理由** | **深挖**：三格填满，再想想它暴露了这个系统什么反直觉的地方 |
| **没给理由** | **是配置不是知识**：一句带过。它就是这个工具的一条约定，照做即可，学不到能带走的东西 |
| **绑在某个工具、某个版本上** | 归到「别抄」：点明它靠什么前提，明年可能就没了 |

> 一句话：**你读的不是别人的流程，是别人的事故史。** 但没带理由的禁令只是一条配置，别在它身上浪费深度。

## 二、让不懂的人看懂：把黑话一层层翻下来

初学者卡住，多半不是因为逻辑难，是因为**黑话**。每遇到一个术语，按这四步往下翻：

1. **不用术语，先说它是什么**
2. **给一个熟悉的生活类比**
3. **说它在这里具体做什么**
4. **说它会怎样影响读者自己**

例：

- **命令行** → 不是点按钮，是用打字给程序下口令的入口。
- **schema（结构规范）** → 规定数据必须有哪些格子、每格装什么的一张表格模板。
- **被悄悄塞进去的人设** → skill 不是你手动点的按钮，是对话一开始就被塞进模型脑子里的一套身份和规矩。你没看见，但它一直在起作用。

**这四步是你脑子里的过程，不是页面上的四行。** 落到页面压成一行：

```
黑话 → 生活类比 → 在这里做什么 → 对你的影响
```

想讲深，在下面另起一句正文，别把这一行撑长。

## 三、每段收一句：能学走的 vs 别抄的

分辨方法就一句话：

> **这个坑是「这一类问题」都有的，还是「这个工具、这个版本」才有的？**

- 这一类问题都有 → **可以学走**（换个 skill 也成立）
- 这个工具、这个版本才有 → **别抄**（明年就没了，照抄等于学噪音）

## 四、五种追问的角度（想不出选择时，拿来找）

上面那个「它本来可以…」的格子填不出来时，从这五个角度找找看。**这是思考素材，不是要在页面上逐条打勾。**

**A. 为什么是这个，不是那个看着更合理的？**
> 例：为什么用「小工作室主理人」而不是「大厂设计总监」？因为大厂总监的职业本能是降低风险，而降低风险恰恰是 AI 最容易犯的毛病。选后者等于让模型去演一个「本能就交出中庸答案」的人。

**B. 它堵掉了哪条退路？**
原文某句话不是在给能力，是在堵一条模型默认会走的舒服路。
> 例：「什么都不做本身也是一种风险」——把「按兵不动最安全」也标成有后果的选择，堵掉「摆烂最稳」这条路。

**C. 它把哪个没法验收的目标，变成了能验收的动作？**
> 例：「要有辨识度」没法验收，「交出一个能指出来的记号」能验收——要么有要么没有。

**D. 它在哪儿留了口子？哪儿沉默了？**
规矩之外的例外和沉默，常常比规矩本身更说明问题。**至少找一处「它没说什么」。**
> 例：它说「大数字配小标签」是套路答案，但没说「永远别用」，而是「除非真的是最好的选择」——留了口子，但把举证责任压给了模型。

**E. 作者在这儿为什么犹豫？**
禁令是**已经解决**的问题；**犹豫是还没解决的问题**——那才是这个领域真实的前沿。凡是出现「优先用 A，但某种情况用 B」「视情况而定」这种**没给干净答案**的地方，都值得单拎出来。
> 指出这一点，比复述任何一条硬规矩都值钱。

## 五、反面教材

- ❌ 「这条体现了对设计的深刻理解，强调了独特性的重要性。」（复读 + 空话）
- ❌ 「配色和字体的选择很巧妙，给人专业的感觉。」（堆形容词，没信息）
- ❌ 「作者在这里用了对比手法，增强了表达效果。」（语文课，不碰思想）
- ❌ 「这里规定不要用 SOLID，因为会渲染成黑色。」（把原文和括号复读一遍，三格一个没填）
- ✅ 「它没说『输出要独特』，它说『先把主角画具体』。因为主角一旦具体了，独特是自然结果。这是把没法验收的目标（独特）换成能验收的动作（给主角起名）的例子。」

最后一条好在哪：它点出了作者真正的手法（**管住输入，而不是管住输出**），并且抽出了一条换个地方也成立的道理。这就是读者能带走的东西——他学走的不是这条规矩，是造这条规矩的思路。
